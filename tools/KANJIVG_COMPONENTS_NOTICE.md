# KanjiVG component data

Gakuji's `kanji_component_trees` SQLite table is generated from KanjiVG.

Creative Commons Attribution-ShareAlike 3.0 license.

- Project: https://kanjivg.tagaini.net/
- Source: https://github.com/KanjiVG/kanjivg
- License: https://creativecommons.org/licenses/by-sa/3.0/

The importer defaults to the `r20250816` main release so its component
hierarchy stays aligned with the KanjiVG release already used by Gakuji's
stroke-order import pipeline.
